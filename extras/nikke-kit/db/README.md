```
db/
  story/{ko,en,ja,zh}/   main/, event/, side/, bond/  (scripts or summaries, one file per chapter)
  voice/{ko,en,ja}/      <character>/ lines.md (+ local audio, not committed)
  images/                <character>/ (local only, not committed)
  index.json             character -> chapters/events they appear in
```
